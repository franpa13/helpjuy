# HelpJuy

Ficha médica de emergencia con QR para Jujuy, Argentina. Cualquier persona carga sus datos médicos de emergencia y obtiene un QR imprimible (billetera, casco, moto). Quien lo escanea, paramédico o testigo, ve al instante lo que necesita para actuar.

- Diseño: [docs/superpowers/specs/2026-11-05-helpjuy-design.md](docs/superpowers/specs/2026-11-05-helpjuy-design.md)
- Boceto de la ficha: [docs/design/ficha-emergencia-v3.html](docs/design/ficha-emergencia-v3.html)

Stack: Next.js · NestJS · PostgreSQL (Neon) · Prisma. Arquitectura por features, spec-driven development.
